# 后续维护

## 兼容性

优先维护微信数据目录检测、消息分库、密钥提取、消息结构和媒体格式。将发现的问题整理为使用虚构数据的回归样例，并记录实际验证过的操作系统与微信版本。

## 两种入口

CLI 和本地网页继续共享 core 中的读取与解析实现。保持 JSON 字段、分页、时间筛选、排序和错误提示的一致性。网页接口保留参数白名单、请求来源检查和媒体路径约束。

## 依赖与辅助程序

Python 依赖在 pyproject.toml 中维护。语音组件与模型更新时同步修改来源、校验值和第三方声明。bin 中的辅助程序保留可核对的来源说明。

## 提交

分支中完成小范围改动，运行相关测试与完整测试，再提交 Pull Request 供朋友审阅。CI 运行 Python 测试和 JavaScript 语法检查。源码安装、命令帮助、网页首页与健康接口是每次整理的基础检查项。

提交前检查文件清单与 Git 差异。分享样例采用人工构造数据，配置示例使用占位路径。
